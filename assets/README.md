# Project Assets & Media

Thư mục này dùng để lưu trữ các tài liệu hình ảnh, video demo phục vụ cho việc minh họa trong file `README.md`.

## Cấu trúc thư mục

*   `images/`: Lưu trữ ảnh chụp thực tế sản phẩm hoàn thiện, ảnh chụp góc làm việc hoặc ảnh chụp màn hình ứng dụng Blynk/Telegram Bot.
*   `videos/`: Lưu trữ các clip ngắn quay các tính năng độc lập, ảnh động `.gif` để nhúng trực tiếp vào README.md nhằm tăng tính sinh động trực quan.

---

> [!NOTE]
> Để nhúng ảnh động `.gif` hoặc ảnh `.png` trực tiếp vào `README.md`, hãy dùng cú pháp chuẩn Markdown:
> `![Tên ảnh](assets/images/anh_san_pham.png)`
